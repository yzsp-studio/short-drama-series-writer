## 🇨🇳 中文

微短剧全流程剧本创作助手：从选题、目标受众、人物关系、爽点节奏、付费卡点，一直到分集大纲、单集剧本和完整导出，系统生成 50-100 集的短剧方案与剧本。适合国内竖屏短剧和出海 ReelShort、DramaBox 等平台，战神、萌宝、逆袭、甜宠、复仇等类型都能套用。所有创作产物以文件形式沉淀在项目目录：创作方案、角色档案、分集目录、episodes/ep001.md 等分集剧本、合规报告和 export/ 导出目录。导出时会生成完整剧本与分集制作包（含分集索引与制作包说明），可直接进入制作。

### ✨ 能做什么

- 输入选题 + 目标受众 → 输出 50-100 集创作方案与角色档案
- 按爽点节奏与付费卡点排布分集目录，逐集落到 episode-directory.md
- 逐集生成 ep001.md 形式的单集剧本，写到 episodes/ 目录
- 生成合规报告，标注风险点
- 一键导出完整剧本 + 分集制作包（含分集索引与制作包说明）
- 全程追踪创作状态，支持中断后接着写

## 🇬🇧 English

A full-pipeline writer for vertical micro-dramas: it walks from topic, target audience, character relationships, payoff pacing and paywall hooks all the way to an episode directory, per-episode scripts and a complete export, producing a 50-100 episode plan and script set. Built for domestic vertical short dramas and overseas ReelShort/DramaBox-style releases, across genres such as war-god, cute-baby, comeback, sweet-romance and revenge. Every artifact lands in the project folder as files: creative plan, character profiles, episode directory, episodes/ep001.md and onward, a compliance report and an export directory. Export generates the full script plus per-episode production packages with an episode index.

### ✨ What it does

- Topic + target audience in, 50-100 episode creative plan and character profiles out
- Episode directory laid out around payoff pacing and paywall hooks in episode-directory.md
- Per-episode scripts written as episodes/ep001.md and onward
- Compliance report generated with the risky points flagged
- One-click export of the full script plus per-episode production packages and index
